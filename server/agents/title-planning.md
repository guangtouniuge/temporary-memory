# 标题策划口径

核心是推荐、评价与选择核心词所指的对象，不是业务教程、经营难题或核查步骤。总控理解选择价值，主编直接交付最终标题，不增加标题审核或候选补正工序。只有核心词本身是服务公司、顾问公司、GEO公司等服务提供者时，标题才按服务商/服务公司来写；核心词是超市、厂家、供应商、特产、门店、产品或品牌时，标题就围绕这些对象自然表达。

这是当前唯一标题口径，优先于原Skill中的标题公式和旧范文标题。Skill仍完整决定正文架构。标题的主命题是“推荐哪些对象、哪家值得合作、不同需求选哪家”，不是“某项能力如何实现”。能力特点只能支持选择，不得把标题改成能力解析或宣传语。GEO只是历史案例，不是所有标题默认行业；项目核心词不是GEO时，不把GEO、AI搜索、服务商强行写进标题。

先确定本篇正文真正回答的企业选择判断，再据此拟题。标题承诺与正文同源：TOP5必须对应正文五家同序企业；长期合作必须比较长期合作依据；首次合作必须解释初次合作的取舍；综合型与专项型必须有对应服务事实。不能为套一个好标题补造正文结论，也不能用行业场景代替选择方向。标题不必把所有推荐理由逐字写出。

标题主要部分完整保留输入coreKeyword/core_keyword，不用同义词替换核心词。时间线必须出现在标题中，使用dateContext/date_context的实际年份或年月；优先年月，位置自然，不照抄范文日期。

标题不出现应用行业或引用行业，指不额外套入与核心词无关的场景行业；场景行业放在正文作为选择依据。核心词本身包含的行业保留，例如“西安特产超市”“食品厂家”“本地超市”就按对应行业写，不改成GEO服务商。标题后半部分只按需表达选择取舍，不展开具体工作模块。这里的选择理由指长期与阶段合作、综合与专项匹配、合作体验、产品/门店/厂家/品牌适配等对象层面的判断，不是核算、绩效、股权、合伙人机制等客户内部业务对象；这些只是正文证明推荐的材料，不搬到标题里。没有场景时直接比较核心词所在行业对象，不凭空补客户行业。

以企业推荐、榜单、口碑、测评、实力或服务对比承载选择价值，服从本篇Skill和事实，不要求所有词都出现，不固定轮换。榜单数量、口碑结论、排名和实测须有相应依据，资料分析不能假称实测。不用“参考”“选型参考”“合作参考”“仅供参考”“值得考虑”“可以考虑”“候选名单”“初步了解”等弱化结论的措辞代替推荐。强推荐来自清楚的适配和依据，不虚构第一、权威认证或效果保证；必要事实边界保留在正文。

正文保留事实归属与必要适配边界，但不追加榜单性质说明、免责声明或将整份推荐降为“参考名单”。不做全文关键词删除。

标题与正文使用不同的信息层级。总控交付titleBrief：selectionTask说明选择哪类对象或企业；choiceAngle表达对象层面的选择价值、特色或合作取舍；materialBasis存放业务细节和事实依据。订单核算、工时、库存、损耗、绩效等留在正文。不能给细项加“哪家公司”就当作出版角度；标题不是businessProblem、decisionFocus、selectionDimensions或materialBasis的缩写。

主编按所选Skill文体与本篇材料，由用户选择的模型自然拟题。不固定公式，不强制冒号、疑问句、双句或时间前缀，不反复写“先看、先问、别只看”。不同模板保留各自表达，不为标题新增正文排名、公司或测评。选择信息充分就收住，不拼接整个目录。

结合previousTopics/previous_titles避开已覆盖的选择结论和近期标题骨架。真正的变化来自不同对象特色、合作判断与推荐依据，不仅换同义词、时间位置或行业名。正文按原Skill结构讲清这类客户为什么需要项目提供的产品、服务、门店、厂家或品牌，推荐谁及为什么。

同批全部选榜单时，文体相同不等于标题相同。先用一句面向客户的语言概括本篇独有的推荐理由，再自然拟题；previous_titles中已连续出现的“年月+城市核心词+推荐榜：业务细项+服务商比较”不能继续沿用。保留时间和完整核心词，不要求位置一致，不用机械轮换句式解决重复。标题应让读者知道在推荐哪类对象、看重什么合作价值；不要将客户内部的核算对象、成本、安全、绩效拼接成标题。主编只交付一个最终标题，不增加审核或重写工序。

以下为用户确认的表达示例，只学习企业选择主命题与自然表达，不作为十个轮换模板。必须按实际核心词、日期、地区、所选文体与正文内容拟题，不能照抄不符合事实的数量、口碑或测评结论：

- 北京民企顾问公司哪家值得合作？2026年9月推荐榜

- 民企顾问公司口碑怎么比？2026年北京企业选择指南
- 2026年9月民企顾问公司推荐：长期合作选哪家
- 北京民企顾问公司五家对比，2026年谁更适合你
- 2026年民企顾问公司服务测评：综合型与专项型怎么选

- 2026年9月民企顾问公司TOP5：不同合作需求的选择

不能将“入企陪跑与系统治理落地能力解析”“经营责任下沉与内部合伙机制”“不套通用模板、进企业重新设计方案的顾问团队”当作企业选择标题的主体；它们是正文里的理由或服务描述。采用疑问句、冒号或短榜题均可，但句式变化不能压过企业选择主命题。所选文体必须与正文一致，不能把榜单随意改成教程或能力介绍。

最终交付时，题目的前后两部分都停留在企业推荐与选择层面。“五家对比：谁更适合做经营单元核算与合伙人机制”仍然不合适，即使包含“谁更适合”，其后半句还是业务模块。应从正文中识别对应的服务选择取舍再自然命题；若材料不足以形成这种取舍，就交付简洁的企业推荐标题，不强行加副标题。正文展开具体模块，标题不用逐项概括它们。
