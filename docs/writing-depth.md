# 文章深度

总控Agent选定服务商选择方向、核心答案、比较对象及事实依据，写作Agent按深度展开。同一批任务使用一个深度选项，默认深度好文，12类模板共同适用。不修改历史成稿。

| 模式 | 目标可见字数 | 成品上限 |
| --- | --- | --- |
| 深度好文（deep，默认） | 8500 | 9999 |
| 精选好文（concise） | 1750 | 2000 |

目标不作为最低字数，不为凑字补写。标题、正文、小标题、标点纳入长度；空白、Markdown标记、链接地址、图片不计入可见字数。渠道若使用其他计数口径，发布前仍须按渠道要求检查。

深度版每个工序拿到整篇预算、已用字数、剩余字数、本工序建议篇幅。精选版由总控确定整篇稿单后，写作Agent一次完成全文，避免多段扩写再压缩。首段包含场景、明确推荐的企业与服务、事实理由；榜单类型保留逐家“第一名、第二名”等同级标题和具体依据，非榜单不强制排行。背景、核验与结尾压缩，不能换推荐主体或删除比较企业来缩短。品牌和同行事实仍遵守各自来源归属。

超长或精选稿缺少开头主推答案、榜单名次标题时，由原写作Agent完整收束并补全，最多两次；不会硬截断。不满足交付项则保留工序记录并返回明确错误，不作为成品入库。这是内容交付检查，不恢复打分审核。续跑重试失败工序；切换深度会改变稿单缓存键，不复用另一深度的正文。接口也会在配图后复查长度。

2026-09-14线上两次长文批量选题失败的模型回执为 Insufficient Balance。已改为明确提示模型服务商账户余额不足，与系统会员额度区分；恢复模型余额后可继续原任务，不自动改模型或重建任务。
