# 商用后台验收清单

以精简栏目、完整业务流程为目标。旧系统仅作为业务参考，不复制所有菜单。后台管理变更不修改冻结的 Skill 或文章生产提示词。

## 本轮已完成并测试

- 总后台与代理后台共用账户资料编辑、密码重置、删除和恢复操作。
- 删除前确认，有未删除下属账户的代理或企业不能直接删除。
- 删除保留项目文章和历史记录，账户进入回收站，已有登录会话失效。
- 恢复账户保持停用状态，需要显式启用；不自动恢复已删除的上级。
- 回收站按管理范围查询，跨代理操作被服务端拒绝。
- 管理操作记入审计记录，不记录明文密码。
- 账户接口测试和真实浏览器交互测试通过；没有操作正式客户账户。

## 尚未完成，不能当作已商用能力

### 2026-09-13 会员账本增量

- 本地增加“会员额度”入口，总后台和代理后台均可使用。
- 独立 SQLite 事务账本，支持八种资源的增减、代理与客户之间转拨、流水、幂等请求及余额版本校验。
- 金额内部使用整数分，页面按元显示；这里是管理员登记余额，不代表在线收款已完成。
- 文章资源一旦分配即启用按篇预占、完成扣减、失败退回；同一后台任务的单篇键防止重复结算。
- 未配置文章资源的历史账户暂不管控；其他七种资源当前只支持分配收回，尚未接实际业务消耗。
- 系统中断留下的预占随原任务续跑复用；任务取消、废弃后的管理释放尚待补齐，不能直接删除带预占的账户。
- 尚无套餐销售、支付回调、代理利润结算，不可据此宣称整套商业闭环完成。
- `member-ledger.sqlite` 及其 WAL 必须纳入一致性备份，部署前验证 Node 原生 SQLite 支持。此轮未部署线上。

以下为整体剩余验收事项（已完成的局部能力以上述增量为准）：

- 点数、余额的实际账本，原子扣减、失败释放、重复请求幂等和对账。
- 空间、项目、关键词、文章和发布额度的实际用量统计与执行。
- 到期配置的执行、接口继承与自定义配置的实际路由。
- 媒体从本地待发布草稿到真实提交、回执、退稿退款的完整流程。
- 认证资料提交、私有文件存储与审核；目前只有审核配置骨架。
- 持久化备份恢复演练及线上完整版本部署。
- 所有其他管理页面的编辑、删除、失败提示和权限逐项验收。

## 后续实施顺序

1. 账户与归属：审计展示、企业交接流程，补齐创建时已有项目和代理归属校验。
2. 资源账本：区分总后台分配额度、账户可用量、已冻结量、已用量，保留交易流水。
3. 接入消费入口：文章、关键词、空间、项目创建及媒体订单；失败释放，重试不重复收费。
4. 媒体闭环：新闻源、自媒体大V的付费订单，与自有账号授权发布分开。
5. 备份、恢复与部署：先用隔离测试数据验收，再部署新系统；不改旧系统。

## 菜单边界

- 总后台：概览、系统配置、代理管理、企业管理、生产任务、媒体订单、操作记录。
- 代理后台：客户企业、额度与费用、发布订单、自身配置。
- 企业后台：品牌资料、关键词库、生成任务、文章库、媒体发布。
- 复杂角色树、多级代理、插件管理、页面装修暂不扩展。
- 实名审核不默认成为写作前置门槛；财务和发布历史不得通过普通编辑伪造。

## 本轮发布状态

### 统一套餐后续增量

- 总后台集中新增、编辑、启停、软删除套餐；代理只能读取并给辖内会员分配启用套餐。
- 套餐包含八项资源、供货参考价和有效天数。历史分配保留快照，不因修改或删除套餐变化。
- 套餐分配与代理资源转出同一事务提交；不足则整体回滚；重复请求不重复转拨。
- 总后台及代理的开户表单增加初始套餐。开户记录与分配事务持久化，账号 JSON 文件作为镜像，重启补齐已提交的开户记录。
- 原账户编辑弹窗的额度填写区改为统一账本入口；历史额度数据未自动迁移。
- 分配记录的有效期支持续期累加，文章生成入口检查到期；其他业务的容量及到期管控仍未完整接入。
- 套餐售价仅为登记，不含在线支付、退款、利润结算。本次仍仅本地更新，未上线。

代码与测试在本地更新。线上尚未部署这批管理功能；完整商用验收未完成。
