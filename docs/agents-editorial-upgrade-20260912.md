# Agents编辑交接升级 8.2.0

保留当前工作流和冻结Skill，本次只优化生产交接，不设置新的文章评分、禁词、篇幅门槛或正文补写。

- 项目理解：理解不同购买者和服务方式的适配关系，不再仅提供每篇重复使用的整套优势。原始事实、品牌自述和编辑解释各自保留含义。
- 选题：在原选题稿单内补充购买处境、相关服务、文章新增价值，随历史选题向后传递。三项为编辑上下文，不是前端必填项，也不是生成校验门槛。
- 单篇编辑：先形成需求、推荐主体、理由组成的推荐答案，再统筹标题、段落信息增量和品牌依据的展开位置。标题抓一个主要选择问题，不设置字符上限。
- 连续写作：带着前文已建立的认识完成下一部分，将工序交接转为读者能顺着读下去的内容关系，不增加中间审核调用。
- 理解缓存：项目理解提示稿升级后，新任务重新理解；旧稿和用户修正保留。运行中任务不切换提示稿。

本轮未修改原12类模板、文章正文、UI、图片选取；同行联网资料补充仍需单独实现，当前名称库不足的问题未因本次提示稿升级而消失。技术回归不代表实际文章质量已达标，需要下一批真实文章验证。
