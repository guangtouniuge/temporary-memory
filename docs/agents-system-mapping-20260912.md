# Agents能力与系统映射

## 本次范围

本地完成生产工作流到已有栏目的映射；不修改冻结的niuge-geo-skill，不更换12类模板。曝光率GEO仍是项目案例，不写入通用工作流。

本地封装版本：8.1.2。完整回归56项通过，包含浏览器操作测试和构建。此结论仅代表本轮功能验证。

| 能力 | 系统入口 | 实际交接 |
| --- | --- | --- |
| 理解推荐主体 | 企业品牌库 → 项目理解 | 项目身份、购买者、客户场景、优势原文、客户价值、推荐逻辑 |
| 使用正确资料 | 品牌知识库、任务资料范围 | 后台按品牌和所选知识库读取原文；不再无视选择混用全部资料 |
| 用户意图 | 关键词、关键词库 | 当前核心词的实际疑问和语义材料；不以固定GEO问句补齐其他行业 |
| 同行材料 | 榜单服务商 | 属于当前品牌的资料供模板按需使用；不是每类文章都强制排行 |
| 两种行业模式 | 创建任务 → 写作场景 | 自己行业：服务购买者；实际场景：由选题环节拓展客户行业 |
| 12类写法 | 创建任务 → 文章类型 | 指定类型沿用，不指定则按选题匹配；每篇读取对应完整模板及范文 |
| 批量差异 | 后台选题环节 | 同批前序选题与本项目历史选题参与下一组选题，不靠生成后换词 |
| 推荐论证及连续文章 | 单篇编辑 → Skill写作 | 全文推荐答案、论证路线、事实意义、段落承接及前文传入后续写作 |
| 看实际生产过程 | 任务详情 | 展示真实选题、稿单、资料来源、写作阶段；不是前端模拟计划 |
| 接口中断恢复 | 任务详情 → 继续本次任务 | 保留原批次与已完成工序，未完成部分继续，不改写已保存正文 |
| 成品使用 | 成品文章库 | 保留编辑、配图、单篇与批量下载，旧审核入口跳转文章库 |

## 本次移出的旧做法

任务页面不再预生成选题计划，不再预填固定GEO痛点、选型维度、FAQ、禁词及品牌理由。不再把未选类型扩成全12类再交给后台。不再展示只修改页面状态、实际不能停服务端任务的“终止”按钮。

历史兼容代码仍有未被活动入口调用的函数，并非本轮全仓删库式清理；这些函数不参与上述任务请求。

## 资料及版本

项目理解存于当前账户项目空间的geo.projectUnderstandingRows，按品牌、知识库范围与来源指纹匹配。用户修正说明独立保存；资料改变后不会沿用过期理解。启动任务保存材料快照，续跑不悄悄换成新资料。

工作流版本封装包括Agents提示稿、范文、资料读取逻辑和执行器。冻结Skill独立校验保持不变。这是程序版本校验，不是文章评分门槛。
