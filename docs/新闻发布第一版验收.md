# 新闻发布第一版验收

本轮只开发小青蛙新闻媒体渠道。12 大平台扫码账号发布未接入，也不与第三方自媒体资源采购混为一谈。

## 已实现

- 新闻页直接调用当前权限范围内的成品库，不依赖页面初始缓存；可选品牌、多个生成任务和单篇文章。
- 新闻媒体分页、价格、案例预览、文章数量分配；发布副本预览不修改原文。
- 服务端重新取得所选媒体页面报价，忽略前端传价；五分钟报价快照。
- 每个文章与媒体组合建立独立持久化订单，确认后原子预占客户余额和发布篇数。
- 投稿前先持久化发送状态，重复请求不重复发稿；响应超时保留待核实。
- 平台受理与返回链接分开显示，不将订单号当作发布成功。
- 查询订单状态及平台确认退款；重复刷新不会重复退款。
- 未发起的预占订单可继续分发或取消；已发起订单不能在本地直接取消退费。
- 案例和结果可在页面内嵌预览，媒体拒绝嵌入时提供独立窗口，不绕过第三方安全策略。

## 验证

- 原有回归与新增开户测试 77 项通过。
- 媒体专项 7 项通过，含 HTTP 模拟供应商的选稿、报价、防重复分发、确认退款全过程，以及浏览器操作测试。
- 模拟测试没有向小青蛙提交付费订单。本轮代码在本地验收，不将模拟成功等同于真实付费验收。

## 剩余边界

- 当前报价按供应商价计算，代理加价及利润结算未接入新闻订单。
- 供应商未明确的状态码不猜测为发布成功。完整状态枚举、超时后按第三方编号找回订单仍需确认。
- 项目图库配图在核价时验证归属、真实路径和文件摘要，转换为随机专用地址。只有确认分发后的订单配图可匿名读取；待确认、已取消的报价不开放图片，整个图库仍需登录。原图被删除或修改后专用地址返回 404，发布后的原图需保留。
- 内嵌浏览器受目标网站嵌入策略约束；线上 CSP 需在发布新版前核对 frame-src。
- 真实付费订单及退款仍需最终小额验收，当前不能宣称已经完成该验收。
