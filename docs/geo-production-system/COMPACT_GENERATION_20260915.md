# 生成链路精简

## 正常路径

复用项目理解 -> 批次分配场景和选题 -> 单篇主编交付最终标题与稿单 -> 作者按 Skill 完成全文。

- 主编直接阅读原始认可范文，不再单独请求范文阅读笔记。
- 主编一次确定最终标题，不再请求标题编辑、定稿与候选补正。
- 总控在分配时比较历史与本批角度，不再额外请求语义去重。保留本地重复检查和有界重分配，但不能保证语义完全不重复。
- 项目理解按资料指纹复用；没有缓存时仍需要一次理解。
- 每篇正常路径为两次模型调用。接口失败、缺项或篇幅收束仍可能增加调用。
- 去掉精选首段与榜单小标题的机械写法审核；这些写法由 Skill 和主编表达，不再因缺少固定词触发改写、打回。字数上限保留。

## 保留边界

Skill 与十二类范文不修改；服务公司选择方向并入主编；深度和精选分别执行原有厚度方案。品牌身份、事实来源和项目隔离保持不变。

每次调用保存检查点，当前任务内失败后只恢复未完成步骤。新流程改变了请求摘要，不能声称旧版本未完成工序可以无条件复用。已完成文章不回写、不重新生成。
