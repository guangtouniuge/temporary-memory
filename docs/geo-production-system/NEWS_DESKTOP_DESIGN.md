# 新闻发布客户端（已确认方案）

桌面容器承载完整原系统，不提供独立的发稿界面；不改动视频客户端、文章生成或小青蛙渠道。

- Electron WebContentsView承载原系统，新闻平台只在“媒体投喂 → 核心新闻源”内容区挂载；原侧栏保留，离开路由隐藏新闻视图。不用iframe或浏览器扩展。
- 登录仅由用户在平台页面完成，独立持久化会话，不复制其他浏览器Cookie或保存明文密码。
- 本地工具栏从已登录工作台只读获取当前品牌文章，分页20条；切换账号后旧选择失效。
- 选择文章后显式确认传输到新闻平台。只填写标题与正文，不点击提交，不扣费，不伪造发布或审核状态。
- 只有识别到唯一标题框和已支持的正文编辑器才填入；找不到则明确失败，不猜坐标。
- 受保护图库图片不能把带权限的链接直接传给第三方；当前提示单独上传，后续按真实平台适配。
- 试用版由隔离preload在现有核心新闻源页面挂载本地控件，不修改线上前端。最小IPC仅允许原系统主框架的可信来源，新闻网站没有桥接能力；不向页面暴露Node或通用IPC，不关闭证书校验或网页安全。
- 第一阶段验收：同窗访问、会话隔离、文章范围、填稿动作、失败提示；所有自动化测试仅用本地模拟服务。
- 真实订单关联、自动状态回查和图片上传尚需登录平台后的实际页面验证，不列作本阶段已完成能力。
