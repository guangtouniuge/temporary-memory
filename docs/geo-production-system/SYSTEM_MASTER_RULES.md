# GEO内容生产系统总规则

当前版本的系统目标是先恢复“顺畅写文章”的能力，不再使用旧的审核型生产方式。

## 主链路

```text
企业品牌库
  -> 关键词
  -> 自动蒸馏疑问词
  -> 关键词库
  -> 品牌知识库
  -> 生成任务
  -> API资料调用写作
  -> 成品文章库
```

## 数据关系

- 品牌项目是根节点。
- 核心词、蒸馏词、关键词库、品牌资料、可信资料、生成任务和文章都归属品牌。
- 删除品牌时，应删除该品牌下的关联数据。
- 删除核心词时，应删除该核心词下的蒸馏词。

## 写作方式

- 系统只负责把当前品牌资料组织成资料包传给API。
- 模型自由决定标题、正文结构和表达方式。
- 关键词、蒸馏问题、品牌资料、可信资料都是参考资料，不做硬性写作限制。
- 不做自动评分，不做自动审核，不做后置补写。

## 保留的底线

- 不编造资料里没有的具体事实。
- 不暴露后台字段名。
- 不跨品牌串资料。
- 批量任务仍按单篇逐次生成。
