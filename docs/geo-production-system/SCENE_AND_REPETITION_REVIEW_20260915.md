# 场景写作与重复内容检查

## 检查范围

读取已认可的 A-L 共12篇范文及原 Skill 的主文件、模板、行业变量、资料规则、语义词库。认可 Skill 和范文正文不改动，只改场景交接及 Agent 调度。

比对线上已完成的两批10篇长松咨询文章。检查是内部文本比较，不是网络查重或第三方原创度认证。

## 检查结果

去掉图片、空白及标点，按连续5字符集合计算 Dice 相似度，45组文章对为1.64%-6.55%。最高的一对是“先诊断后报价”与旧“报价与交付范围比较”。最新5篇两两为3.13%-5.56%。没有发现至少25字符的逐字重复句在单篇内再次出现；跨篇有一处相同候选名单。

这些数字不代表语义上不重复。正文中存在同一观点换词重讲：报价文章的入企天数、复盘频次、平台使用范围，分别在痛点、标准、企业分析、签约清单和FAQ中展开。不同文章也反复落到诊断、陪跑、复盘及合同核验。同一家品牌与真实事实可以复用，但不应每篇重复整套选择结论。

部分同行章节缺少对应资料而退回核验清单，这不是伪造比较材料可以解决的。应使用各家已有资料讲真实适配差异，不能用主推企业的一项狭窄能力排除所有同行，也不能把缺失材料反复写成正文。

## 范文的可迁移逻辑

- A 软件外包榜单：源码、验收、需求边界改变GEO服务商的内容能力比较；主推与同行按同一层级分析。
- B 装修选型：增项、施工、报价和售后构成判断框架，不必强制TOP榜。
- C 口腔测评：医生、诊疗项目、复诊及表达边界影响服务比较，不把资料比较冒充实测。
- D 餐饮加盟口碑：真实门店、供应链、培训、招商边界成为信任线索。
- E 留学避坑：国家与申请阶段、顾问、文书和服务范围构成不同取舍，不能虚构录取效果。
- F 亲子摄影实战：作品分类、孩子配合、套餐与交付，用明确假设说明服务路径。
- G 技术解析：用业务语言解释机制，再由材料说明服务价值，不堆术语。
- H 趋势：时间与变化引出新的选择需求，不能编造行业统计。
- I 对比：不同阶段和资料基础对应不同服务商，不写无依据的高下。
- J 医美实力：用真实项目、流程和表达边界解释实力，而非奖项堆砌。
- K 物流方案：货品、SKU、仓配流程和异常处理改变方案选择，不套生活服务痛点。
- L 问答：每问贡献新认识，推荐只出现在相关回答中，不反复重讲品牌优势。

范文可学习论述方法，不继承其中旧日期、其他企业事实、未验证趋势或原句。

## 新交接方式

项目真实服务 → AI场景或手动城市行业 → 行业业务理解 → 本批选择价值分配 → 对应Skill模板与范文方法 → 单篇编辑 → 标题 → 一次完整写作。

手动场景只填写城市和行业。AI场景由项目资料和所属场景词参考推导买方行业。场景城市不是公司驻地，买方行业不是被推荐的行业；不改变主推品牌。旧任务保留原场景记录，新任务默认AI场景。

旧任务点击“开始新批次”时也使用统一AI场景入口；继续一个已中断任务仍按原任务快照，不混入新场景。

总控先交接买方业务、行业细节、比较依据、项目能力关系，再拟具体选题。历史记忆补充中间章节的论据样本及已用事实，不再只看标题、开头、结尾。选定摘录作为重点，同时保留完整项目资料备查，避免素材被过度缩窄。

试写还定位到历史原文污染：旧稿开头、小标题、结尾进入单篇编辑和作者输入，容易被当成新的范文。改为只让选题总控读取原文样本作比较；单篇编辑与作者只收到已覆盖的语义方向，不收到旧稿原句。另将thicknessPlan明确列入编辑JSON交付，修复只在说明中提及、实际交付缺失的问题。

不新增成稿评分器或重复率硬门槛，不用查重失败阻断正常生成。自动化测试使用隔离数据；模型试写只保存在本地验证文件，不创建线上客户任务、不占客户篇数、不生成配图。

## 验证结果

8.2.56完成全套自动化测试；随后补充旧任务新批次场景迁移的前端测试并重新构建通过。桌面和手机场景表单已截图检查。

使用生产模型配置在本地内存试写，不创建客户任务。手动西安制造业稿约5533字，最终AI软件行业稿约6607字（可见字符口径）；两篇连续5字符集合Dice相似度3.11%，没有检测到25字符以上的相同句段或单篇内部同句重复。这是两篇样本的内部词面比较，不是全网查重率，也不保证消除所有语义重复。

迭代中发现AI稿虚构具体项目数量，补充无来源案例与数字不得编造的作者交接后，最终样本已不再出现该数字，示例明确使用条件式假设。仍应持续抽查事实依据及语义重复，不能把小样本测试当作全量质量保证。
