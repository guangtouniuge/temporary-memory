# 图库与AI配图计费

## 行为

- 图库首页只有自有导入、AI生成两条分类及当前项目图片数量。点击后进入带缩略图、预览、删除和20条分页的列表。
- 上传只选图片，不要求填写场景、分类、用途或说明。旧图片元数据保留。
- AI配图每篇两张合计2元，从现有会员money余额扣款，不增加价格套餐或代理定价配置。自有图库不收生图费。
- 请求前检查余额和空间，实际生图前事务预占200分。两张成功保存后确认扣费，失败释放预占。
- 图片费用由服务端确定，不接受客户端传价。订单键绑定账户及单篇任务，重放不重复扣费，已保存图片不重复调用。
- 取消或文章租约过期释放未结算的图片预占；已成功的图片费用不因后续文章失败退回。
- 与新闻发布共用现有余额，预占、成功和退款均进入原会员流水。没有修改客户的存量余额或追扣历史图片。
