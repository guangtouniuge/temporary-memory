# 提示词规则重置说明

本文件已按当前决策重置。

旧版本中的高分文章、新闻口吻、标题公式、正文结构、FAQ、图片位、审核评分、90分入库、重复度闸门等写作限制全部下线。

当前系统提示词只做一件事：把品牌项目资料交给模型，让模型根据资料自由写一篇文章。

## 当前资料输入

- 项目名称
- 推荐名称或品牌简称
- 行业
- 城市
- 核心词
- 蒸馏问题参考
- 关键词库语境参考
- 品牌资料
- 可信资料

## 当前输出要求

- 第一行输出标题。
- 后面输出正文。
- 不输出JSON。
- 不输出规则说明。
- 不暴露后台字段名。
- 不编造资料里没有的具体事实。

## 暂停项

- 豆包高分审核。
- 新闻稿口吻约束。
- 企来客式固定框架。
- 强推荐标题模板。
- 固定字数。
- 固定段落。
- 固定FAQ。
- 图片位要求。
- 审核拦截和补写。

后续如果重建写作提示词，应先验证“API能否自然写出可读文章”，再逐步增加少量必要约束。
