# 任务列表与重新生成

## 交互

- 品牌文章系统菜单依次为生成任务、任务列表、成品文章库。
- 生成页只显示当前选中的一个任务，下面展示流程状态和本次实时生成的文章，支持直接预览正文。
- 流程不再展开资料来源、选题问题、模型交接稿单和论据；保留必要错误原因与失败续跑入口。AI配图状态也纳入流程。
- 任务列表保留旧任务与批次，可查看原文章、查看任务或重新生成。
- 重新生成二次确认，创建独立任务名、batchId和jobId，不覆盖原任务；失败续跑仍使用原任务和检查点。
- 刷新后先等待服务器任务和文章数据加载，再恢复当前任务轮询，避免旧缓存抢先写回。

## 总控

- 新批次清除自动生成的editorialBrief，读取当前项目资料与项目理解，历史文章及任务选题作为已覆盖内容进入新规划。
- restartOf仅用于新批次规划意图；服务器验证原任务所属账户和品牌，运行中的任务不可重新生成。
- 首轮真实测试发现虽换行业，仍重复核算/绩效因果链。重新生成指令增加对历史论证套路的归纳，要求改变有资料依据的核心合作判断，而非仅换行业标签。不增加独立审核工序、不改写Skill模板。
- 字面/语义差异是规划与现有重复检查的职责，不能保证任意模型输出绝无内容相似。
