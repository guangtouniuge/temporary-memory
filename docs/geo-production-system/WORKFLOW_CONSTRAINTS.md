# 工作流约束重置

旧写作约束已全部暂停。

## 当前只约束流程

- 必须先选择品牌项目。
- 必须使用当前品牌下的数据。
- 核心词保存后可自动蒸馏问题。
- 关键词库按行业、语义、场景、区域拓展，作为语境参考。
- 品牌资料和可信资料进入生成资料包。
- 生成任务按单篇顺序调用API。
- API返回文章后直接进入成品文章库。

## 当前不约束内容

- 不限制新闻口吻。
- 不限制标题样式。
- 不限制标题字数。
- 不限制正文字数。
- 不限制段落数量。
- 不强制FAQ。
- 不强制表格。
- 不强制图片位。
- 不做豆包评分。
- 不做90分入库。
- 不做重复度拦截。

## 保留的数据安全线

- 不跨品牌调用资料。
- 不把后台字段名写进正文。
- 不编造资料没有提供的具体事实。
- API无正文时记录接口失败。
