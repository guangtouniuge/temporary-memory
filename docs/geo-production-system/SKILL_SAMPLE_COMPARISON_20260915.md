编辑取舍：主推事实仅在同场比较中充分解释；后续推荐结论回答适合谁及取舍，不再逐条翻译同一组材料。同行有各自资料时展示其真实特点；资料不足时明确比较范围，写有依据的服务类型差异，不把“没资料”当作同行能力差的证据，也不虚构四家优势来补齐形式。

## 总控应该如何调配

不再新增一层笼统的“请自然、不要重复”要求，而是在已有稿单里落实：

1. 先说明本篇采用哪一类Skill写法，以及最终帮助读者完成哪一种服务商选择；标题忠实表达这一选择价值。
2. 每个模块交付一个新的认识，填写已有newAnswer、materialFocus、handoff。若两个模块的新认识相同，编辑阶段合并解释，不让作者各扩一遍。
3. 材料安排到最能解释它的位置。区分原文事实、适配推理、待确认事项；后文引用结论，不能把推理升级为事实。
4. 同行资料的可用性决定比较深度。总控不能许诺五家细项横评，而作者收到的只有主推资料和其他名称。
5. thicknessPlan的omit要具体：例如“第五节不重复第四节的核算/绩效材料，直接按企业基础给适配结论”，而不是仅写“避免重复”。
6. 保留Skill核心结构和推荐逻辑，不强制所有文章复制范文字数、段数、句子及旧企业事实，不新增成稿分数或自动打回。
